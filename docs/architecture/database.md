# Database Architecture

Finance One uses **PostgreSQL** configured via **Prisma ORM** (`apps/server/prisma/schema.prisma`).

---

## 1. Schema Models & Types

### Enums
```prisma
enum Category {
  FOOD
  FUEL
  SHOPPING
  BILLS
  ENTERTAINMENT
  HEALTH
  TRAVEL
  EDUCATION
  SUBSCRIPTION
  GIFT
  OTHER
}

enum Priority {
  ESSENTIAL
  GOOD_TO_HAVE
  LUXURY
}

enum BudgetPeriod {
  WEEKLY
  MONTHLY
  QUARTERLY
}
```

### Core Entities

#### User
```prisma
model User {
  id           Int           @id @default(autoincrement())
  name         String
  email        String        @unique
  passwordHash String
  createdAt    DateTime      @default(now())
  updatedAt    DateTime      @updatedAt
  transactions Transaction[]
  budget       Budget[]
}
```

#### Transaction
```prisma
model Transaction {
  id              Int          @id @default(autoincrement())
  amount          Decimal
  category        Category
  priority        Priority
  title           String?
  notes           String?
  transactionDate DateTime
  createdAt       DateTime     @default(now())
  updatedAt       DateTime     @updatedAt
  userId          Int
  user            User         @relation(fields: [userId], references: [id])
}
```

#### Budget
```prisma
model Budget {
  id         Int          @id @default(autoincrement())
  amount     Decimal
  periodType BudgetPeriod
  startDate  DateTime
  isLocked   Boolean      @default(false)
  userId     Int
  user       User         @relation(fields: [userId], references: [id])
  createdAt  DateTime     @default(now())
  updatedAt  DateTime     @updatedAt
}
```

#### SkillEmbedding (AI / Intent Matching)
```prisma
model SkillEmbedding {
  id          Int      @id @default(autoincrement())
  skillId     String
  exampleText String
  embedding   Unsupported("vector(2560)")
  model       String
  dimensions  Int
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt

  @@unique([skillId, exampleText])
}
```

---

## 2. Integrity Rules & Invariants

1. **Foreign Key Restraints**: All transactions and budgets are strictly scoped to a valid `userId`.
2. **Precision**: Currency amounts are stored as `Decimal` types to avoid floating-point rounding errors.
3. **Immutability on Locked Budgets**: When `Budget.isLocked = true`, application services prevent updates or deletions.
4. **pgvector Storage**: Vectors (2560 dimensions, generated by `nomic-embed-text`) are indexed for cosine distance queries inside PostgreSQL.
